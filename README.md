
# Privacy First Utility Tools

Starter Next.js + Tailwind project for:
- Mobile-first homepage
- Scan to PDF tool
- PWA-ready structure
- Privacy-focused branding
- Ad placeholders
- Cloudflare Pages deployment

## Setup

1. Install Node.js
2. Run:
   npm install
   npm run dev

## Deploy to Cloudflare Pages

Build command:
npm run build

Output:
.next

Framework preset:
Next.js
